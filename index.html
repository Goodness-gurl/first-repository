Cascading Style Sheets (CSS) is a style sheet language used to specify the presentation, visual design, and layout of documents written in markup languages like HTML, XML, SVG, and MathML. Alongside HTML (which provides structural foundation) and JavaScript (which adds interactive logic), CSS is one of the three core cornerstone technologies powering the World Wide Web.
